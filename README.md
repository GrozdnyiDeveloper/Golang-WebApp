# Дипломный проект - Сайт интернет-магазина бытовой техники

Дипломный проект — часть программного комплекса интернет-магазина бытовой техники.
Отвечает за пользовательский интерфейс и взаимодействие с API.

## 🚀 Стек технологий

**Backend:**
- Golang
- [gorilla/mux](https://github.com/gorilla/mux) — маршрутизация
- [sqlx](https://github.com/jmoiron/sqlx) — работа с PostgreSQL
- [go-redis](https://github.com/redis/go-redis) — сессии и логи

**Frontend:**
- HTML/CSS/JS
- Bootstrap 5
- jQuery, DataTables, PurePajinate

**Базы данных:**
- PostgreSQL — основное хранилище
- Redis — сессии и логи

**Связь с БД:** через отдельное [API-приложение](https://github.com/GrozdnyiDeveloper/Golang-Api).

## 📋 Функциональность

Приложение поддерживает 4 роли:

| Роль | Возможности |
| :--- | :--- |
| **Гость** | Просмотр каталога, карточек товаров |
| **Клиент** | Корзина, оформление заказов, история заказов, скидочная карта, смена пароля |
| **Товарный менеджер** | Управление товарами и заказами, статистика продаж, системные логи |
| **Администратор** | Всё выше + управление пользователями |
